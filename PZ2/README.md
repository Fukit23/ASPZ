# Практичне завдання 2

Цей репозиторій містить рішення завдань з дослідження сегментів пам'яті, роботи стека викликів та управління віртуальною пам'яттю в ОС Linux.

## Вимоги до середовища

* **ОС:** Linux (наприклад, Ubuntu) або середовище WSL.
* **Компілятор:** `gcc`.
* **Інструменти:** `size`, `gdb`, `pstack` (або `gstack`).

---

## Опис завдань

### Завдання 1: Дослідження `time_t`
**Файл:** `2,1.c`

Демонструє розмір типу `time_t` та перевіряє поведінку системи щодо максимального значення часу (проблема 2038 року для 32-бітних архітектур).

**Запуск:**
```bash
gcc 1.c -o task1
./task1
```

### Завдання 2.2: Дослідження сегментів файлу
**Файл:** '2,2.c'

Програма показує розподіл змінних та масивів між сегментами виконуваного файлу. Глобальні масиви потрапляють у Data або BSS, тоді як локальні створюються динамічно на стеку.
Для перевірки зміни розмірів сегментів використовується утиліта size.

Запуск та перевірка:
```
gcc 2_2.c -o task2_2
size task2_2
```
